01 / THE PROJECT

Project Overview

A repeatable workflow that transforms raw Excel timesheet exports into structured, validated Google Sheets reports.

The automation detects new files in Google Drive, prevents duplicate report generation, extracts employee time entries, normalizes supported formats, flags questionable records, and sends a report-ready notification.

02 / WHY IT EXISTS

The Problem & The Solution

Less repetitive cleaning. More clarity about what needs attention.

BEFORE / MANUAL REVIEW

Messy inputs. Hidden inconsistencies.

Timesheet exports can contain mixed formats, missing information, duplicates, overlapping shifts, and discrepancies between reported and calculated hours.

Manual cleaning is repetitive, and questionable records can be missed or demand extensive investigation.

AFTER / STRUCTURED VALIDATION

Organized outputs. Visible exceptions.

Supported formats are standardized. Records without unresolved issues become READY; questionable records become PENDING_REVIEW.

Original records remain available, and detected issues are documented for human verification.

↳ Automation handles supported normalization. People resolve uncertain or conflicting records.

04 / INSIDE THE AUTOMATION

Step-by-Step Workflow

Seven stages. A traceable journey from source file to final notification.

01

Google Drive / n8n

Monitor new time exports

A file-created trigger watches a designated Google Drive folder. The RAW-file filter allows only relevant exports to continue.

A controlled entry point for incoming timesheets.

02

Google Drive / n8n / Gmail

Prevent duplicate reports

The workflow searches for a corresponding report before processing the export.

If a report exists, Gmail sends the existing-report notification and that branch stops. Otherwise, the file continues to extraction.

One decision. Two distinct execution paths.

03

Google Drive / n8n

Download and extract Excel data

The export is downloaded and its time entries are extracted: employee names, work dates, clock-in and clock-out times, reported hours, assignments, and notes.

Source information stays available for comparison and auditing.

04

JavaScript / n8n

Validate and normalize data

JavaScript standardizes supported formats and evaluates records for inconsistencies. Uncertain information is flagged for verification.

  • Inconsistent date formats
  • Duplicate entries
  • Overlapping shifts
  • Missing or invalid values
  • Reported vs. calculated hours
  • Conflicting information
✓ READY

No unresolved issues requiring manual review.

! PENDING_REVIEW

Missing, conflicting, or questionable information needs human verification.

05

Google Sheets / Google Drive / n8n

One report. Four perspectives.

The automation creates a Google Sheets report and writes four structured datasets in separate branches. Explore the actual output from the sample run.

Preserves original employee time records for reference, comparison, and auditing.

Standardized records, calculated information, and validation statuses in one reviewable dataset.

Detected issues, affected records, and recommended actions make the review process traceable.

A concise overview of processing results and the quality of the sample dataset.

06

n8n / Google Sheets API

Synchronize and format reports

Node 17 waits for all four report-writing branches. Spreadsheet metadata is then retrieved and formatting requests are prepared.

Standard formatting is applied first, followed by advanced formatting through the Google Sheets API.

Formatting begins after all required report tabs have been written.

07

Gmail / n8n

Send the report notification

After report generation and formatting, Gmail sends the new-report notification with report information and access to the generated tracker.

This is the final success notification, separate from the earlier existing-report branch.
